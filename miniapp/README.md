# HF Moderation — Telegram Mini App

Node.js-сервер (без внешних зависимостей) + фронт для Telegram Mini App.
Работает с той же базой `database.json`, что и Python-бот.

## Запуск

```bash
cd telegram-bot/miniapp
node server.js            # http://localhost:8787
```

Переменные берутся из `../.env` (BOT_TOKEN, ADMIN_IDS) — как у бота.
Опционально: `PORT`, `DATA_DIR`.

## Подключение к боту

1. В @BotFather: `/newapp` или Bot Settings → Menu Button → задай URL сервера.
2. В `handlers/` бота добавь кнопку WebApp (url = адрес сервера).

## Вкладки

- **Профиль** — ник, ID регистрации (#1, #2, ...), должность, подписка, статистика.
- **Наказания / Проверки** — личные логи.
- **Сессии** — попытки входа в клиент: принять / отклонить (клиент получает kick-флаг),
  история входов; новые попытки оповещаются тостом каждые 5 сек.
- **Ключи** (админ) — создание, блюр ключа (глазик / ховер), отзыв, сброс, +30 дней, удаление.
- **Модераторы** (админ) — список с активностью, профиль модератора отдельной
  страницей: вся информация, его наказания/проверки, бан/разбан/выгнать/удалить.
- **Статистика** (админ) — общие числа и топ по активности.
- **Devlog** — версии мода; админ может публиковать новые.

## Тема

Акцент `#7086ff`, тёмный фон `#0e0f13` (см. `public/styles.css`).

## Безопасность

- `/api/auth` проверяет подпись `initData` (HMAC от BOT_TOKEN).
- Дальше — Bearer-токен с HMAC-подписью (30 дней).
- Админские маршруты требуют `ADMIN_IDS` из `.env`.
